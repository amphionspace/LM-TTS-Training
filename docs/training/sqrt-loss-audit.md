# sqrt 实验前2000步 loss 对照

2026-09-10，针对“loss 看起来与旧实验没区别”的只读排查。旧run为 `emilia-en-zh-dynamic-10000h`，新run为同名加 `-sqrt`。本次没有改变训练代码、配置或进程。

sqrt 已实际参与反向传播。当前证据支持：样本长度权重发生了明显变化，但总体 CE 尺度与下降形状仍接近；前2000步没有观察到普通 token CE 的收益。没有证据把曲线接近归因于配置未生效、TensorBoard串了run，或分布式归一化失效。是否改善短句、牺牲长句，以及这种分配是否有利于最终生成，当前汇总指标不能回答。

## 实现与指标口径

`qwen3_train/model.py:16` 计算全样本有效长度幂的和；`:198–202` 将逐token CE乘上长度的 -1/2 次方。`qwen3_train/train.py:449–461` 对归一化分母跨rank求和，把 `first_reduced_sum / normalizers[0] + 0.3 * residual_reduced_sum / normalizers[1]` 实际用于反向传播。它没有在后续重新换回 token objective；全局梯度裁剪也不会把不同样本的相对权重恢复成原来的值。

设每句平均 CE 为 c_i，有效长度为 n_i：

- token：`sum(n_i * c_i) / sum(n_i)`。
- sqrt：`sum(sqrt(n_i) * c_i) / sum(sqrt(n_i))`。

首码本 n_i=T_i+1，包含EOS；残余码本 n_i=15*T_i。两者都是归一化的加权平均CE，不是对CE开平方，也不是把整体loss乘一个较小系数。因此数值仍然在相同尺度。如果各句c_i相同，任意长度权重给出的标量就完全相同；一般情况下，差异取决于长度与每句CE的联合分布。标量差异小不能证明梯度或参数更新相同，也不能证明每个句长区间表现相同。

`first_ce` / `residual_ce` 保留token平均；`first_sqrt_ce` / `residual_sqrt_ce` 是新目标的两部分。不能用新run的sqrt CE与旧run的token CE直接判优。已从32001端口HTTP读取两个实际run的scalar数据并对照train.log，确认不是误选旧run或显示问题。

本次重新运行已有的逐句独立CE与整批聚合对照，三种模式的loss及全部参数梯度测试通过（`tests/test_correctness.py:72`，证据 `main-sqrt-loss-audit-test.log`）。已有两卡、accumulation=2、变长且各卡样本数不同的sqrt梯度对照结果也复核过：FP32相对误差3.10e-7，BF16/FA2、冻结speaker/frontend条件下0.00404。本次未额外占用训练GPU重跑分布式测试。当前checkpoint签名是sqrt；从step0初始化，原assembled权重指纹与旧run相同。

## 实际权重改变有多大

读取6,869,742条训练清单，使用相同seed42及四卡6000帧/9000token打包算法重建前2000步，覆盖714,005次样本使用；重建的每个已记录step的样本数、音频帧数和Talker token数与运行日志一致。按每个更新先归一化再在2000次更新中平均，首码本各区间权重如下：

| 音频长度 | token权重 | sqrt权重 |
| --- | ---: | ---: |
| ≤2秒 | 6.28% | 12.60% |
| 2–5秒 | 30.25% | 41.08% |
| 5–10秒 | 25.78% | 24.76% |
| >10秒 | 37.68% | 21.56% |

全数据句长P10/P50/P90为1.44/3.52/10.48秒，最长30秒；前2000步分布基本相同。每次更新平均357条样本，范围282–415。两种权重分布的平均total variation为0.1776；按loss权重计算的平均音频长度从10.95秒降到7.63秒。英语权重从49.95%升到51.93%，中文从50.05%降到48.07%。不能把当前结果解释为“句长几乎一样，sqrt没改变权重”。以上是权重分配，不是梯度贡献占比；每句梯度方向和大小另需实际测量。

## 同一步数、同一指标的结果

验证集为同一512条，普通token平均CE：

| step | 旧token first CE | 新sqrt first CE | 旧token residual CE | 新sqrt residual CE |
| --- | ---: | ---: | ---: | ---: |
| 500 | 5.20792 | 5.49157 | 7.29269 | 7.30505 |
| 1000 | 2.30485 | 2.40856 | 7.09644 | 7.12085 |
| 1500 | 1.92721 | 1.95683 | 6.86156 | 6.89158 |
| 2000 | 1.77980 | 1.81112 | 6.71701 | 6.74654 |

2000步新run普通first/residual CE分别高约1.76%/0.44%，并未优于旧run。训练和验证都仍在下降，没有依据把“曲线相似”描述成训练卡住。

在同一个新模型上，只改变聚合口径：1500步first从1.95683变为1.88640（降低3.60%），residual从6.89158变为6.89034（降低0.018%）；2000步first从1.81112变为1.73968（降低3.94%），residual从6.74654变为6.73713（降低0.139%）。这直接解释了为什么残余CE曲线尤其接近：当前长度重加权对它的汇总标量影响很小。没有逐句CE，不能进一步把这种小净差异解释为所有句子难度相同；不同区间的变化可能抵消。

## 结论与尚不能确定的部分

本轮改动解决的是长样本按token数量占更多权重的问题，不会直接改变模型结构、监督信号或每个码本预测的问题本身。它已经重新分配了训练关注，但这并不保证整体token CE下降更快。从前2000步结果看，该收益尚未出现。

下一项有区分力的诊断是：在两个run的同step checkpoint上，分别报告≤2秒、2–5秒、5–10秒、>10秒的验证CE与样本等权CE，并配合同目标的短句内容完整率、提前EOS、长句截断和低能量输出。这样才能判断是短句改善被总体指标掩盖、长短句收益相抵，还是各区间均无改善。当前没有这些逐句teacher-forcing结果，不宣称已经定位“为什么优化无收益”的最终机制，也不据汇总曲线直接切换sample loss或修改网络。原定训练继续到19000步。
