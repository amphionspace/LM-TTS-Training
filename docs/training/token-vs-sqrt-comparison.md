# Token 与 sqrt loss 实验性能对比

2026-09-11；分析截至双方均已完成的 **17500步**。生成评估、训练日志和波形均直接读取现有产物，本次没有改变训练代码、配置、排队计划或进程，也没有重新进行GPU推理。

**当前结论：token的普通验证CE小幅、持续领先；计算成本基本一致；生成表现互有优劣，尚无足够证据用sqrt替代token作为默认训练目标。** sqrt改变了长度权重，但未稳定改善整体生成质量，也没有消除短句过早EOS。该判断是当前单次实验、有限评估集下的阶段性结论，不能当作两种loss普遍优劣的证明。

## 对照范围与公平性

| 项目 | 对照方式 |
| --- | --- |
| 实验 | `runs/emilia-en-zh-dynamic-10000h` 与 `runs/emilia-en-zh-dynamic-10000h-sqrt` |
| 初始化与数据 | 相同assembled权重指纹、seed42、训练/验证清单与模型结构 |
| 训练配置 | 只改变loss模式与输出目录；四卡、6000帧/9000token、accumulation1、学习率、残余权重0.3保持 |
| 验证CE | 同一512条验证样本；500–17500共35个共同检查点；均比较普通token平均CE |
| 生成比较 | 10000–17500共16个检查点；另汇总15000–17500最近6轮及17500单点 |
| 生成策略 | 两边同为greedy、min_new_frames=2、max_frames=400、相同codec与ASR配置 |
| 生成配对 | 每模式固定8个目标（4英文/4中文），目标文本、ID、参考ID/音频/文本/帧数一致；10000以后参考ASR结果也完全一致 |
| 训练效率 | 对照11000–17500的651个共同日志点，避开token早期人工暂停和恢复阶段 |

截至17500的1750个共同训练日志点，global_samples、global_audio_frames、global_talker_tokens、主干/新参数LR逐点完全相同。因此当前差异没有表现为两个实验实际消耗了不同批次规模或使用不同学习率。

token早期生成没有最短2帧保护，10000步产物已经用修复后的策略补全；更早的生成不用于公平排名。两次运行的暂停、恢复、评估耗时不同，所以不能直接以开始到现在的总墙钟时间比较loss效率。

## 收敛与验证损失：token小幅、持续领先

以下全部是普通token平均CE，数值越低越好：

| 步数 | token first CE | sqrt first CE | token residual CE | sqrt residual CE |
| --- | ---: | ---: | ---: | ---: |
| 2000 | 1.77980 | 1.81112 | 6.71701 | 6.74654 |
| 5000 | 1.51682 | 1.52806 | 6.33256 | 6.35839 |
| 10000 | 1.37006 | 1.38050 | 6.02474 | 6.05783 |
| 15000 | 1.29988 | 1.30948 | 5.88294 | 5.91390 |
| 17500 | **1.26832** | 1.28020 | **5.83626** | 5.86732 |

- 35个共同检查点中，sqrt的first和residual CE均高于token。这说明差距在本次运行的各阶段持续存在，不能把它当作某一个batch的波动；这些检查点相互相关，也不代表35次独立实验。
- 17500步sqrt的first CE高0.01188（0.94%），residual CE高0.03106（0.53%）。同口径总损失 `first_ce + 0.3 * residual_ce` 为token 3.01920、sqrt 3.04040，差约0.70%。15个残余码本在该步的CE均是sqrt略高。
- 两边损失仍在下降，没有训练停滞证据。sqrt的自身`first_sqrt_ce`较低不能直接与旧run的`first_ce`判优，因为是不同聚合口径。

token直接优化token平均CE，sqrt改变优化偏好，所以token在这个指标上占优并不自动证明所有句长或音质都更好。当前尚无两个run同一步数的逐句teacher-forcing CE，不能确认是否存在短句收益与长句损失相抵；也没有跨随机种子的重复实验。

## 生成内容：模式、语言和观察窗口影响结论

英文采用`summary.english.wer`，中文采用`summary.by_language.zh.cer`；以下均为百分比，越低越好。跨检查点汇总先累加编辑错误数和参考长度，再求比率。

| 模式/指标 | 10000–17500 token | 10000–17500 sqrt | 最近6轮 token | 最近6轮 sqrt |
| --- | ---: | ---: | ---: | ---: |
| speaker_only 英文WER | **43.06%** | 49.48% | **45.37%** | 46.76% |
| speaker_only 中文CER | **52.38%** | 53.72% | 57.54% | **54.96%** |
| ICL 英文WER | 12.85% | **11.98%** | **11.11%** | 11.57% |
| ICL 中文CER | **50.22%** | 55.06% | 55.36% | **52.78%** |

“最近6轮”指15000、15500、16000、16500、17000、17500。同一策略窗口每个run/模式有128份输出，最近窗口有48份，但它们仍只是相同8个目标反复评估，不能当作128或48个独立测试样本。

具体解读：

- speaker_only英文在两个窗口均是token略好或较好；sqrt没有稳定的内容优势。
- 中文近期两种模式的汇总CER都是sqrt较低，但扩大到10000以后全窗口，优势反转。因此更适合描述为近期局部改善，不能判定总体胜出。
- ICL英文两边接近，换窗口会改变领先方；不到1个百分点的差异，在4条固定英文目标上不足以支持普遍排名。
- 两个run的ICL英文都明显好于speaker_only，这是当前8条诊断样本上较清楚的共同现象。但ICL仍会整句过早结束，汇总WER不能替代对失败样本的检查。

17500单点进一步说明不能只看一个检查点：

| 17500步 | token | sqrt |
| --- | ---: | ---: |
| speaker_only 英文WER | **25.00%** | 38.89% |
| speaker_only 中文CER | **55.95%** | 76.19% |
| ICL 英文WER | 19.44% | **16.67%** |
| ICL 中文CER | 63.10% | **44.05%** |

该点token的speaker_only较好、sqrt的ICL较好；最近六轮差距则明显缩小，不能将单点结论推广到整体。

## 短句、长句和结束行为

10000–17500同策略窗口，每个run/模式共128份输出：

| 可观察问题 | token SO | sqrt SO | token ICL | sqrt ICL |
| --- | ---: | ---: | ---: | ---: |
| 达到400帧上限而截断 | 0 | 0 | 1 | 0 |
| 只生成2帧/0.16秒 | 0 | 0 | 8 | 16 |
| 生成时长超过目标2倍 | 8 | 3 | 1 | 0 |
| 存在至少2秒连续低能量段 | 0 | 0 | 1 | 0 |

低能量定义为10ms窗口RMS<0.001，是可复核的波形诊断阈值，不是主观音质评分；超过目标两倍也只是时长异常线索，不自动等于读错。全部512份同策略窗口WAV读取通过，均24kHz、非空、数值有限且时长符合metrics。

- **ICL短中文sample-04**（“其实，人家毕竟坚持了这么多年。”）：sqrt在该16轮中全部只有2帧；token有4轮只有2帧。17500时两边均失败。sqrt虽然提高短句权重，仍未解决这个目标的过早EOS。0.16秒结果的ASR“字幕by索兰娅”不能当作有效内容。
- **ICL短英文sample-00**（“The the liquid spears.”）：token有4轮仅2帧，sqrt没有；17500时token为2帧，sqrt为16帧。这里sqrt更稳定，但参考音频ASR本身也只识别一个“the”，不能据转写单独断言模型漏读了重复词。
- **SO短英文sample-05**（“W.A. Flinders Uni.”）：token生成帧数范围24–108，sqrt为23–39，sqrt减少了这个目标的过长输出；但两边仍有明显额外内容或错词，时长改善不等于内容解决。
- **SO较长英文sample-02/06**：全同策略窗口英文WER，token分别6.25%/21.88%，sqrt为18.75%/34.90%，token更好。它们也说明sqrt对部分短句的变化不能代表所有句子受益。
- **较长中文sample-03**：10000以后token ICL还有一次400帧截断和长低能量段，sqrt没有；最近六轮两边均无此类问题。该目标仅6.28秒，不能用它代表训练清单中10–30秒长语音的能力。
- **尾句sample-12**：两边ICL仍出现尾部内容缺失或合并，17500均约3.36秒，对应目标5.28秒；需要结合原音与实际听评进一步判断。没有400帧截断不等于完整读完。

最近六轮ICL的2帧结果都是6/48，但分布不同：sqrt集中在sample-04，token分布在sample-00和04。两边都存在固定或反复失败的目标，不能把其中任何一个描述为短句问题已经解决。

## 训练与生成效率：基本相当

11000–17500共同651个训练日志点的中位数；单步时间不包含该步后续checkpoint、验证、ASR和生成评估：

| 指标 | token | sqrt |
| --- | ---: | ---: |
| 更新耗时 | 2.132秒 | 2.150秒 |
| 音频吞吐 | 883.2音频秒/墙钟秒 | 875.3音频秒/墙钟秒 |
| rank0当步峰值allocated显存 | 55.73GiB | 55.67GiB |
| 取批等待 | 0.278毫秒 | 0.285毫秒 |
| 裁剪前梯度范数 | 0.4270 | 0.4637 |

sqrt单步中位数约慢0.88%，显存差异不足0.1GiB，实际可视为接近；两次运行的主机负载并非严格控制，不能将这不到1%的耗时差直接归因于sqrt实现。两者动态batch规模和填充相同，所选区间全部训练指标有限，无持续供数问题。梯度范数变化也不等于梯度方向更好或更差。

最近六轮排除2帧失败输出后，实际评估生成每帧耗时中位数：SO为token 0.3378秒、sqrt 0.3375秒；ICL为0.3434秒、0.3384秒。该路径每帧重新进行前向、不是部署推理基准；输出长度和参考长度会影响耗时，不能将更早结束造成的低总延迟当性能收益。模型结构相同，现有测量没有显示实质性的推理成本差异。

## 判断、限制和下一步

如果现在选择训练基线，我倾向保留 **token**：它在普通验证CE上持续领先，计算成本相当，sqrt尚未给出足够稳定的生成收益。sqrt仍有局部价值信号，包括部分目标更少过长输出、ICL某些短句更稳定；但它也有持续的固定短句EOS失败，不能称作全面改善。

这次结论不包含MOS、说话人相似度、韵律/自然度或真实部署延迟；未主观试听。英文专名、重复词和缩写受ASR识别影响，中文CER还受繁简与数字写法影响，当前规范化不统一中文繁简/数字读法。ASR在极短或低能量输出上可能产生无关文本。所有生成比较仅8个独立目标，且没有覆盖训练集中>10秒的长目标，证据不足以判断总体TTS质量或长度重加权的全部收益。

按原计划完成sqrt的19000步，再顺序启动已授权sample实验。sample排队请求已于2026-09-11 02:48 UTC被原后台确认received，此分析不改变该计划。后续真正能区分三种目标的是：同一步数、同一批覆盖短中长时长的独立验证样本；同时报告token平均、样本平均及分时长CE，扩大配对生成并检查EOS/截断/内容完整性，补充盲听和说话人相似度。sample加强短句权重也不保证优于两者，应作为对照实验看待。
