# runs 清理与保留规则

更新于2026-09-10，依据用户当前要求。`runs/` 保留本说明和以下两个正式实验目录：

| 必须保留的目录 | 实验 |
|---|---|
| `emilia-en-zh-pretrain-1000h/` | 已完成5000步的中英1kh正式实验 |
| `emilia-en-zh-dynamic-10000h/` | 正在运行的中英10kh正式实验，目标两个epoch、38539步 |

**两个目录及其全部现存内容必须保留。** 包括完整checkpoint（分片、优化器、scheduler、RNG和COMPLETE）、配置、日志、TensorBoard、全部评估音频与指标、源码/数据准备归档、修复证据、清理清单和巡检记录。不能因为文件较旧、训练结束或已有新checkpoint就人工删除。

当前训练器按其既有 `keep_checkpoints: 2` 配置轮转checkpoint；本规则不授权额外人工清理。1kh正式实验不再作为新训练输出。

清理前先读取本文件，核对运行进程和文件引用。以后出现的其他目录也应先确认用途；删除上述两个正式实验或缩减其内部内容，需要用户明确授权。

本次旧实验清理清单见 `emilia-en-zh-dynamic-10000h/cleanup-20260910/`。数据和模型依赖仍保留在 `runs/` 之外，完整范围见 [实验与依赖保留说明](../docs/training/run-retention.md)。Git不会备份这些实验产物。
